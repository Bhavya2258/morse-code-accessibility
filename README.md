# Morse Code Accessibility

Morse Code Accessibility is a web and Android application that enables users to encode, decode, and communicate using Morse code through an accessible and easy-to-use interface.

## Features
- Morse code encoding and decoding
- Accessibility-focused design
- Web and Android support
- Built with React, Vite, and Capacitor

## Technologies Used
- React
- TypeScript
- Vite
- Capacitor
